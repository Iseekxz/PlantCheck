# 🌾 Агро-Ассистент (PlantCheck)

**Агро-Ассистент** — это умный Telegram-бот, предназначенный для экспресс-диагностики болезней сельскохозяйственных культур, выдачи рекомендаций по лечению с учётом погодных условий и оперативного связи с живым агрономом-экспертом.

---

## 📝 Описание проекта

Проект решает проблему своевременного обнаружения болезней растений (кукурузы, пшеницы и подсолнуха.). Бот использует двухуровневую каскадную систему искусственного интеллекта:

1. **Быстрая локальная диагностика (YOLO)** — моментально сканирует изображение листа на предмет характерных поражений.


2. **Мультимодальная верификация и консультация (Google Gemini)** — перепроверяет выводы YOLO, исключает ложные срабатывания (если растение здорово или на фото посторонний предмет) и генерирует рекомендации с учетом погоды в регионе.


3. **Система «Human-in-the-Loop»** — перенаправляет сложные кейсы живому эксперту с сохранением полного контекста.



---

## 🛠 Используемый стек и сторонние технологии

### Основной стек:

* **Язык программирования:** Python 3.10+


* **Telegram Bot Framework:** `python-telegram-bot`

* **Асинхронность и утилиты:** `nest_asyncio`, `requests`, `Pillow`


### AI/ML Модели и Облачные API:

* **Ultralytics YOLOv8 (`best.pt`)** — предобученная и дообученная локальная нейросеть для классификации болезней.


* **Google Gemini 3.6 Flash API (`google-genai`)** — мультимодальная модель для верификации изображений и выполнения функций текстового агронома-консультанта.


* **OpenWeatherMap API** — получение актуальных метеоданных (температура, влажность, осадков) для г. Кокшетау.

## 🤖 Данные и AI (Соответствие правилам хакатона)

### Источники данных и открытые датасеты:

* **Датасеты для обучения YOLO:** В качестве основы использовались открытые датасеты патологий растений (*PlantVillage / Kaggle Open Datasets*).

* **Синтетические данные:** Синтетические данные использовались **исключительно для аугментации** датасета (повороты, изменения яркости/контраста, добавление шума для повышения устойчивости модели к реальным фото).
* Все данные взяты из открытых источников и не нарушают авторских прав.
* https://www.kaggle.com/datasets/olyadgetch/wheat-leaf-dataset/data?select=wheat_leaf
* https://www.kaggle.com/datasets/noamaanabdulazeem/sunflower-fruits-and-leaves-dataset
* https://www.kaggle.com/datasets/andresmgs/plantdec?resource=download

### AI-ассистенты и сторонний код:

* **AI-ассистенты при разработке:** В процессе написания и отладки кода (промпт-инжиниринг, обработка исключений) использовался ассистент Gemini.
* **Шаблонный код:** Использованы стандартные обертки библиотеки `python-telegram-bot` и официальный SDK `google-genai`.

## ⚡ Разработано непосредственно во время хакатона

В рамках хакатона нашей командой с нуля было выполнено:

1. **Проектирование гибридной архитектуры:** Объединение узкоспециализированной модели vision (YOLO) и универсальной LLM (Gemini) в единую каскадную систему.


2. **Интеграция погодных условий:** Разработка логики, при которой ИИ корректирует сроки и методы обработки растений на основе API погоды в реальном времени.(https://openweathermap.org/api)


3. **Промпт-инжиниринг:** Составление и тестирование защищенных промптов для Gemini с целью устранения «галлюцинаций» и точной обработки двух сценариев (здоровое/больное растение).


4. **Система вызова эксперта (Human-in-the-Loop):** Реализация логики передачи контекста (изображение, предсказание YOLO, ответ ИИ, вопрос) администратору и механизм обратного ответа пользователю через команду `/reply`.


5. **Мультиязычность:** Реализация поддержки русского и казахского языков интерфейса и ответов ИИ.


6. **Система аналитики:** Автоматическое логирование обращений пользователей и найденных патологий в файл `statistics.csv`.

## 🚀 Инструкция по запуску

### 1. Клонирование репозитория

```bash
git clone https://github.com/ВАШ_АККАУНТ/PlantCheck-main.git
cd PlantCheck-main

```

### 2. Установка зависимостей

Убедитесь, что у вас установлен Python 3.10+.

```bash
pip install -r requirements.txt

```

*(Или `py -m pip install -r requirements.txt` на Windows)*

### 3. Настройка конфигурации

В файле `bot.py` укажите ваши актуальные ключи доступа:

* `TELEGRAM_TOKEN` — токен вашего Telegram-бота


* `GEMINI_API_KEY` — API-ключ Google AI Studio


* `WEATHER_API_KEY` — API-ключ OpenWeatherMap


* `ADMIN_ID` — Ваш Telegram ID для получения заявок эксперту



Также убедитесь, что файл обученной модели `best.pt` находится в корневой папке проекта.

### 4. Запуск бота

```bash
python bot.py

```
