
# Plantcheck Bot 
Умный Telegram-бот для фермеров Акмолинской области.
Определяет болезни растений по фото с помощью YOLOv8 и дает рекомендации по лечению с учетом текущей погоды через Google Gemini API.

## Как запустить локально:
1. Клонируйте репозиторий и перейдите в папку проекта: `cd Plantcheck`
2. Установите зависимости: `pip install -r requirements.txt`
3. Вставьте свои API ключи в файл `bot.py`
4. Запустите скрипт: `python bot.py`
